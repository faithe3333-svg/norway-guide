  • Hurtigruten 邮轮：当时只有 17 号班次；两人 424 澳元 ≈ 4114；挪威版两人 3658 ≈ 2547 RMB。
  • Navik → Svolvær：罗弗敦上被严重低估的一段。极夜季节从特罗姆瑟一路公交到最南端 Å 镇，300 路车 Navik–Svolvær 这段很绝——粉色天空、烟雾缭绕的海面、五颜六色的小房子。
  • Bodø 博德：北挪威第二大城市（仅次于特罗姆瑟）、北极圈门户。本身知名度不高，多是前往罗弗敦的中转站。景点「萨尔特流」号称地球最强水漩涡：
    • 距市区 28km，约半小时，出租车固定往返 1900 NOK（司机会在漩涡处等）；邮轮下船即有出租车，也有公交（需提前看时间）。
    • 谷歌地图搜 Viewpoint Saltstraumen 定位桥上观景点，两排大小漩涡群非常壮观，桥上风大，观测强度受天气影响（晴天/夏季更佳）。

Supabase 云同步

把本机数据同步到 Supabase，手机 / 电脑改一次、处处同步。需要一个免费的 Supabase 项目（首次创建步骤见下方）。同步采用「整库快照 + 最后写入优先」，适合单人多设备使用。

首次使用：如何创建 Supabase 项目（约 2 分钟）
  1. 打开 https://supabase.com 注册并新建一个 Project（免费层即可）。
  2. 左侧菜单 SQL Editor → New query，粘贴并运行下面这段建表 SQL：
create table if not exists norway_sync (
  id text primary key,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table norway_sync enable row level security;
create policy "anon_rw" on norway_sync
  for all to anon using (true) with check (true);
  1. 左侧 Project Settings → API，复制 Project URL 和 anon public key，填到上方两个输入框。
  2. 点「连接并同步」即可。之后每次修改会自动上传，打开页面会自动拉取。

⚠️ 该 anon key 会被打包进网页（纯前端无法避免）。免费个人项目、仅你自己用、数据无敏感信息场景下可接受；若要更严格，可在 Supabase 里改用带密码的 policy 或自建后端。请勿把含银行卡密码等真正敏感的数据写进此攻略台。
